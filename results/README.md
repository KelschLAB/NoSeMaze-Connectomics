# Results

This directory contains outputs generated by the manuscript figure scripts.

```text
results/
├── main/
│   └── Figure_*/
└── supplement/
    └── Figure_S*/
```

Depending on the panel, outputs may include:

```text
PDF figures
PNG figures
CSV source-data tables
CSV statistical summaries
analysis metadata
MAT result objects
RDS result objects
session/provenance information
```

## Regeneration

The corresponding reproduction script is located under:

```text
figures/
```

Use [`FIGURE_MAP.md`](../FIGURE_MAP.md) to navigate between figure code and results.

## Principle

`results/` contains generated outputs and should not be used as an upstream source-data location unless a figure-specific README explicitly states otherwise.

Do not manually edit generated statistics/source-data tables if they can be regenerated from the corresponding script.
