# Reappraisal NBS

Within-conditioning NBS analyses are implemented in the corresponding
manuscript figure scripts.

Their inputs are derived BASCO correlation matrices from:

```text
data/processed/fMRI/functional_connectivity/reappraisal/basco/v11/
    correlation_matrices/
```

This folder is retained only to document that within-cohort NBS belongs
downstream of BASCO. There is no additional standalone NBS pipeline to run.
