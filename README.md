# NoSeMaze-Connectomics

Code, processed/source data, and reproducibility material supporting the NoSeMaze connectomics study:

> **Subordination experiences disrupt network adaptivity, biasing negative hippocampal recall**

This repository contains the figure-level analysis code used for the manuscript together with the upstream MATLAB preprocessing and analysis workflows required to understand how the public figure inputs were generated.

## Start here

For manuscript figure reproduction:

1. open [`FIGURE_MAP.md`](FIGURE_MAP.md);
2. navigate to the relevant folder under [`figures/`](figures/);
3. read the figure-specific `README.md`;
4. run the corresponding MATLAB, R, or MRIcroGL script;
5. generated outputs are written under [`results/`](results/).

Each computational figure folder contains its own README describing:

- panel definitions;
- required input files;
- analysis settings;
- statistical tests;
- software/helper dependencies;
- expected output files.

## Data-availability boundary

Raw MRI acquisitions, raw RHD recordings, original videos, and large intermediate processed datasets are **not distributed in this repository** because they remain in active use for ongoing analyses and additional manuscripts.

The repository is therefore designed around two levels of reproducibility:

### Figure-level reproduction

The scripts under `figures/` operate on the processed/source inputs made available for this manuscript and generate the corresponding outputs under `results/`.

This is the primary route for reproducing the reported manuscript figures.

### Preprocessing and upstream analysis provenance

The code under `src/matlab/` documents the preprocessing and analysis sequence used to transform the private raw data into the derived inputs used by the manuscript.

Some preprocessing stages necessarily require:

- non-public raw data;
- historical acquisition-specific readers;
- SPM12 / AFNI / MRIcroGL or other external software;
- project-specific reference files.

These boundaries are documented in the module-specific READMEs.

## Software

The repository contains MATLAB, R, and MRIcroGL scripts.

Depending on the analysis, external dependencies include:

- MATLAB;
- MATLAB Statistics and Machine Learning Toolbox;
- SPM12;
- AFNI;
- BASCO;
- Brain Connectivity Toolbox / NBS-related routines;
- R with the packages specified in the relevant figure/module README;
- MRIcroGL for MRI rendering panels.

Exact dependencies are documented locally rather than requiring every dependency for every analysis.

## Running figure scripts

Run figure scripts from the saved repository structure. For example:

```matlab
run('figures/main/Figure_4/panel_A_localGA_histograms.m')
```

or in R:

```r
source("figures/supplement/Figure_S14/figure_S14_fraction_losses_mediation.R")
```

MRIcroGL scripts are run from MRIcroGL's embedded Python environment as described in their figure-specific READMEs.

Most MATLAB and R figure scripts determine the repository root from their own saved location and therefore do not require machine-specific absolute paths.

## MATLAB setup

`setup_project.m` is only a convenience helper. It does **not** recursively add the complete `src/matlab` tree to the MATLAB path, because the repository contains analysis-specific toolboxes/functions with potentially overlapping names.

For upstream preprocessing or analysis, use the relevant module-specific `main_*` entry point described in:

[`src/matlab/README.md`](src/matlab/README.md)

## Reproduction outputs

The `results/` directory contains outputs generated by the current figure scripts, including where applicable:

```text
PDF / PNG figures
CSV source data
CSV statistical summaries
analysis metadata
MAT / RDS result objects
```

These files provide a direct record of the output obtained from the repository version of each script.

## Related NoSeMaze resources

The open-source NoSeMaze hardware/software project is maintained separately by the Kelsch Lab. This repository focuses on the behavioral, fMRI, functional-connectivity, graph-analysis, and eyelid analyses supporting the present manuscript.
